Anti-pattern tôi chọn là small files trong pipeline LLM observability. Ingest theo micro-batch nhỏ tạo nhiều data files và log entries; query tốn công mở và lập kế hoạch đọc file trước khi scan dữ liệu. NB6 minh họa 200 commits trên 100.000 dòng tạo 200 file; compaction còn 11 (18×), còn clustering cho phép bỏ qua 90% file trong point lookup. Đây là số liệu lab, không phải benchmark production. Tôi sẽ điều chỉnh trigger và target file size, theo dõi file count, kích thước file và log growth, chạy compaction sau ingest, rồi cluster theo bộ lọc phổ biến. Retention cần an toàn cho reader; orphan cleanup cần đối chiếu metadata với file trên đĩa và có age guard.

AI hỗ trợ đọc tài liệu, chạy các kiểm tra và notebook, thu output thật, rồi biên tập bản nháp này. Tôi sẽ tự kiểm tra kết quả và xác nhận phần giải thích trước khi nộp.
